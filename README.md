# MultiTask-ESG-Score-SDG-Goal-Prediction-Domain-Guided
Multitask model for ESG reports &amp; SDG Goals: predicts total ESG score (regression) &amp; SDG labels (multi-label classification). Combines sentence embeddings, contextual features, improved NN + ensemble, focal loss, optimized thresholds. Achieves RMSE 1.15, R² 0.978, F1 0.982.
